# Kishk Digital Atlas (preview)

A searchable, bilingual (English/Arabic) record of traditional kishk production in the
Chouf and West Bekaa: ingredients, ratios, fermentation, drying, milling, packaging,
storage and lab results. Each record is linked to the published research it comes from.

**Live preview:** https://nizarsh98.github.io/kishk-digital-atlas/

This repository only holds the generated static site (plain HTML/CSS/JS, no build step).
It is published from a private source project, so changes made here will be overwritten.

## Status
- Built only from published, cited literature. Field documentation (recipes, SOPs,
  photos, video) is still being collected with producers' consent.
- Records were transcribed from the papers and are pending expert review. The Arabic
  text is a draft pending native review.
- This is an independent prototype, not an official AUB publication. The production
  Atlas is planned for AUB hosting with controlled access and backups.

## Sources
Content paraphrases and cites: Chedid et al. 2018 (J. Food Research, CC BY 4.0),
Tamime et al. 1999 (Le Lait), Salameh et al. 2016 (Powder Technology) and Abd El-Razik
et al. 2016 (Food and Nutrition Sciences, CC BY 4.0). Full citations are on the
Sources page.
